| Authentication & Onboarding | Logout | As a user, I want to log out so I can securely end my session. | Logout clears refresh token cookie; access token invalidated on client side; activity logged; redirect to login. |
| Authentication & Onboarding | Password Reset Request | As a user, I want to request a password reset so I can regain access if I forget my password. | User enters email; reset token generated and stored; token expires in 1 hour; email sent with reset link. |
| Authentication & Onboarding | Password Reset | As a user, I want to reset my password using the reset token so I can create a new password. | User enters reset token and new password; token validated and expiration checked; password strength requirements enforced; account unlocked. |
| Authentication & Onboarding | Change Password | As a user, I want to change my password so I can keep my account secure. | User provides current password; new password validated for strength; password updated; activity logged; session remains active. |
| Authentication & Onboarding | Account Lockout | As a system, I want to lock accounts after failed login attempts so I can prevent brute force attacks. | Account locks after 5 failed attempts; lockout duration is 30 minutes; failed attempts counter tracks attempts. |
| Authentication & Onboarding | Account Status Management | As an admin, I want to manage user account status so I can control access. | Account can be ACTIVE, INACTIVE, or SUSPENDED; inactive users cannot login; status changes logged. |
